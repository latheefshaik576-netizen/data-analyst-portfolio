# Shaik Latheef — Data Analyst Portfolio

A responsive, professional one-page portfolio starter designed for data analyst internship applications.

## Before publishing
1. Replace the placeholder contact details with your real professional email, LinkedIn URL, and GitHub URL.
2. Update the project cards with your completed analyses, screenshots, findings, and repository links.
3. Remove any skill you cannot confidently discuss in an interview.
4. Do not claim projects or results as completed until you have done the work.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `data-analyst-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will usually look like:
   `https://YOUR-USERNAME.github.io/data-analyst-portfolio/`
6. Open the URL on your phone to test it, then paste it into the internship's Portfolio/Work Samples field.
